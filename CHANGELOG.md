# Changelog

## 1.0.0 - 2026-07-13

- Established a fresh public release root with no predecessor commit ancestry.
- Limited the public boundary to rules, schemas, canonical synthetic data, documentation, and release tooling.
- Published the rule surface as JSON-only; legacy Markdown drafts remain in the private archive.
- Removed raw model outputs, provider run metadata, internal handoffs, local configuration, and application materials from the public surface.
- Reframed all dataset labels as rule-derived synthetic targets rather than ground truth.
- Added deterministic validation and Hugging Face package manifests.
- Added a dated regulatory-policy snapshot and explicit non-deployment limitations.
- Corrected current FSAP/CWC annotations, permissible toxin amounts, policy outcome tags, and incomplete rule strings without relabeling the synthetic corpus.
